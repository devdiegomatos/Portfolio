Projeto final de Programação Concorrente 2024.02: Segmentação de Imagens usando método limite (Thresholding).

Principal objetivo do trabalho é aplicar concorrência na leitura das imagens para aplicar o método, também foi desenvolvido uma interface gráfica usando Qt6 e C++ para o usuário: selecionar a imagem, escolher modo sequencial ou concorrente do programa, rodar o solver, salvar o resultado. Veja também o [código fonte](https://github.com/devdiegomatos/UFRJ-Laboratorios/tree/main/programacao-concorrente-2024-01/trabalho-final).
